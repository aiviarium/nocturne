The demo is a small product built only from Nocturne.
`createShell` registers its scopes, lenses, places and panels, and `<Shell>` draws the window.
Every exported part appears in one of its places, so each can be tried where an app would use it.
Its data is in memory, and what it remembers stays in this browser.

<DemoFrame to="projects/atlas/explore/issues" />

The address after the hash is the demo's place, so every view has a link.
The site's theme switch restyles it.
The app menu, behind the icon at the top left, turns it into a desktop window, with history arrows and window controls.
Below 720px wide it takes the phone layout.

## Keys

| Keys | What they do |
| --- | --- |
| ⌘K | Search, places and actions in the box |
| ⌘1 to ⌘3 | Switch a project's lenses |
| J and K | Step through the list a record came from |
| ⌥D, ⌥A, ⌥T | Toggle Details, Assistant and Terminal |
| ⌘[ and ⌘] | Walk the window's history |
| Esc | Close the topmost thing, then go up from a record |

## The source

The demo is `demo/` in the repository.
`bun run demo` serves it on port 4830, and `bun run demo:build` builds it.
A test fails when an exported part isn't used in it.
Each new part comes with a place to try it.
