title: Overview
description: The part to use for each thing a view shows, from the shell down.
---

Build every view from these parts.
Views then look and behave alike, however many teams or modules write them.
Don't restyle a part for one view.
If a part lacks something, add a variant to it and update its page.

The tables start from the window and go down to the smallest mark.
Each row gives the part, the page with its rules, and a place in the [demo](../demo.mdx) where it's used.
On a phone each part takes the phone scale by itself, see [Phones](../phones.mdx).
