Every icon is a [Lucide](https://lucide.dev) icon, drawn on its 24px grid with one stroke weight, in `currentColor`.
Nocturne never draws an icon by hand, so every icon in a view has the same weight and style.

```tsx
import { Icon } from "@aiviarium/nocturne"
import { Camera } from "lucide"

<Icon name="home" />
<Icon node={Camera} />
```

`name` takes one of the icons in `scripts/icons.ts`.
`node` takes any other icon from `lucide`.

`scripts/icons.ts` maps each name to its Lucide icon.
`bun run gen:icons` writes `src/components/icon-data.ts` and the SVG files in `icons/` from it.
To add a name, add a line there and run the script.

## Sizes

<Example id="icon/sizes" />

Use 13px inside chips, menus and cells, 16px in buttons and navigation, and 20px in empty states.
An `IconButton` holds a 16px icon at 28px, and a 13px icon at 24px.
See [Actions](./parts/actions.mdx#iconbutton).
