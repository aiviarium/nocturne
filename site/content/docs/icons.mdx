The core icons are drawn on a 16px grid with a 1.5 stroke, in `currentColor`.
The files are in `icons/`, and `bun run gen:icons` writes `src/components/icon-data.ts` from them.

```tsx
import { Icon } from "@aiviarium/nocturne"
import { Camera } from "lucide"

<Icon name="home" />
<Icon node={Camera} />
```

`name` takes a core icon.
`node` takes any icon from `lucide`, for what the core set lacks.
