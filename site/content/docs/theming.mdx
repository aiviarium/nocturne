## The root

```html
<div class="nc" data-theme="dark" style="--accent: #8b7cf6">…</div>
```

- Put `class="nc"` on the root of the app.
- Set `data-theme="dark"` or `data-theme="light"` on the same element.
- Set `--accent` on that element to change the accent.

The tokens for each theme are on `[data-theme]`, so a subtree can take the other theme.
Dark is the default: `tokens.css` declares the dark values on `:root` as well.

## The accent

`--accent` is the one colour an app sets.
The default is Iris.
`ACCENTS` lists the six presets the gallery offers, and `accentValue(id, theme)` gives the value of a preset in a theme.

```ts
import { accentValue } from "@aiviarium/nocturne"

root.style.setProperty("--accent", accentValue("jade", "dark"))
```

The other accent tokens (`--accent-strong`, `--accent-text`, the tint, line and glow) hold the Iris values in `tokens.css`.

## Overlays take the theme

Popovers, menus, dialogs, tooltips and toasts render in the top layer, at their place in the page.
They inherit the theme and accent of that place.
See [Overlays](./overlays.mdx).

## Parts and props

Each component root has a stable `data-part` attribute, such as `data-part="list-row"`.
Tests and app CSS can find a part by it.
Props are documented with TSDoc in the sources.

## Editor classes

The editor's classes are `nc-editor`, `nc-editor__content` and `nc-editor-*`.
