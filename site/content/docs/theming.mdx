## The root

```html
<div class="nc" data-theme="dark" style="--accent: #8b7cf6">…</div>
```

- Put `class="nc"` on the root of the app.
- Set `data-theme="dark"` or `data-theme="light"` on the same element.
- Set `--accent` on that element to change the accent.

The tokens for each theme are on `[data-theme]`, so a subtree can take the other theme.
Dark is the default: `tokens.css` declares the dark values on `:root` as well.
An app with the shell lets [Appearance](./shell/appearance.mdx) set `data-theme` on `<html>`.

## The accent

`--accent` is the one colour an app sets.
The default is Iris.
`ACCENTS` lists the six presets the gallery offers, and `accentValue(id, theme)` gives the value of a preset in a theme.

```ts
import { accentValue } from "@aiviarium/nocturne"

root.style.setProperty("--accent", accentValue("jade", "dark"))
```

<AccentTable />

`bundle.css` derives the other accent tokens from `--accent` in each theme: `--accent-strong`, `--accent-text`, the tint, line, glow and the focus ring.
`tokens.css` holds their Iris values, which the site reads for its tables.
See [Colour](./tokens/colour.mdx#accent) for where the accent may go.

## The accent follows the lens

The lens that is on drives `--accent` and its family for the whole window, overlays included.
The appearance sets it on `<html>`, as `data-nc-accent` with the lens's hue.
A scope without lenses uses the base accent, and so does the window when the person turns off "Accent follows lens".

`--accent` is a registered property, so the change cross-fades in `--dur-accent`, 100ms.
Under reduced motion it changes at once.
Text selection and the caret never take the accent or the lens's hue.

## Overlays take the theme

Popovers, menus, dialogs, tooltips and toasts render in the top layer, at their place in the page.
They inherit the theme and accent of that place, and the accent of `<html>` when they mount at the page's root.
See [Overlays](./overlays.mdx).

## Parts and props

Each component root has a stable `data-part` attribute, such as `data-part="list-row"`.
Tests and app CSS can find a part by it.
Props are documented with TSDoc in the sources.

## Editor classes

The editor's classes are `nc-editor`, `nc-editor__content` and `nc-editor-*`.
