Nocturne was already the design system of the prototype, and its `ui/` folder was the components under the
name `@crow/ui`. In the first version they are a repository and a package of their own,
`@aiviarium/nocturne`, that any app can install.

| In the prototype | In Nocturne |
| --- | --- |
| `ui/` in the Crow repository, published as `@crow/ui` | This repository, published as `@aiviarium/nocturne` |
| `ui/src/components` | `src/components`, with the same components |
| `ui/src/editor`, `ui/src/fields`, `ui/src/lib` | `src/editor`, `src/fields`, `src/lib` |
| `ui/src/styles`, with its cascade layers | `src/styles`, with the same layers |
| `ui/examples`, and the gallery the script builds | `examples/`, and the gallery from `bun run gallery` |
| Icons read from the `design/` snapshot | Lucide alone, by the names in `scripts/icons.ts`, and `bun run gen:icons` |

## What is new

| Added | For |
| --- | --- |
| `ChatMedia` | Images and attachments in a message |
| `LiveWidgets` | Compact live widgets at a size you pick |
| `LogViewer` | A job's or a service's log |
| `ShellHeader`, `SidebarHeader` | The shell's top bar, and the sidebar's header with its workspace crumb |
| The site | Tokens, every part with an example, the gallery, and the phones page |

`docs/phone.md` and the phones page of the site say the same thing about phone mode, so a change to one is
a change to the other.

## What is not here

- No network code. Anything that talks to a backend comes in through a provider or a prop, such as
  `EditorServices`, `TranscriberProvider`, the field runtime, `ViewLayoutHost` and `ViewChrome`.
- The shell and the plugins that use these components live in
  [Crow](https://github.com/aiviarium/crow).

The release's list of what is left out is Rookery's [Not in this
version](https://rookery.helight.dev/docs/reference/not-in-this-version).
