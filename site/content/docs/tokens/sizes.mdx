## Spacing

Spacing is the 4px grid.

<LengthScale prefix="space" kind="space" />

The library also uses three values on purpose.

| Value | Use |
| --- | --- |
| 6px | The selection inset, the inner padding of a row, the gap in a `MetaLine`, the radius of controls |
| 10px | The gap between an icon and its label in navigation and menus |
| 14px | The larger widget and panel insets |

Any other spacing is a mistake.

## Radius

<LengthScale prefix="radius" kind="radius" />

| Token | Use |
| --- | --- |
| `--radius-xs` | `kbd`, inline code, marks |
| `--radius-sm` | Buttons and fields at every size |
| `--radius-md` | Cards, frames, code blocks |
| none | Viewport containers, such as the view area and the docked panels |
| `--radius-lg` | Menus, popovers and board lanes |
| `--radius-xl` | The composer |
| `--radius-2xl` | Widgets and the cards on a `WidgetGrid` |

## Controls

<LengthScale names={['control-sm', 'control-md', 'control-lg']} kind="height" />

`sm` is for dense rows, list rows, table bars and toolbars.
`md` is for forms, panels and dialogs.
`lg` is for empty states.
Fields are 30px, the height of a compact row.

## Rows and headers

<LengthScale names={['row-default', 'row-compact', 'header']} kind="height" />

List rows, table rows, sidebar items and data list rows are 30px, the only row height on a desktop.
There is no comfortable density.
`--row-compact` is the same 30px and stays for parts that name it.

The title bar is 44px, `--header`. The sidebar header, the view header and the panel headers are 36px, `--header-view`, and 44px on a phone.
On a phone, rows are 44px and 58px, see [Phones](../phones.mdx).

## The shell

<LengthScale names={['rail', 'sidebar', 'panel-rail']} kind="space" />

| Token | Use |
| --- | --- |
| `--rail` | The sidebar folded to its icon rail |
| `--sidebar` | The sidebar's width before the person resizes it, from 200px to 360px |
| `--panel-rail` | The panel rail at the window's right edge |

The view area and its docked panels have no radius.
See [The app shell](../shell/index.mdx#the-layout).

## Motion

<LengthScale names={['ease', 'dur-hover', 'dur-fade', 'dur-accent']} kind="motion" />

| Token | Use |
| --- | --- |
| `--ease` | The one easing |
| `--dur-hover` | Hover, which changes colour only |
| `--dur-fade` | Things that appear, such as menus, popovers, the palette, dialogs and toasts |
| `--dur-accent` | The accent's cross-fade on a lens switch |

The durations are 0 under reduced motion.
Content swaps never animate.
A new place, lens, record, tab or panel drill replaces the content in the same frame.
