## Sizes in the parts

- Body text in a view is 13/20, `.body`.
- A section heading is 13px semibold, see [Views](../parts/views.mdx#section-heading).
- Labels above fields and secondary text are 12px.
- Group labels in a sidebar or menu are 11px in `text-3`, `.section`.
- An inline title is 20/28, `.title`.
- On a phone the parts take larger sizes, see [Phones](../phones.mdx#the-compact-phone-scale).
